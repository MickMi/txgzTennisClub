# 分享海报使用指南

> 腾讯广州网球社小程序 · 赛事结束后，一键生成精美战绩海报，保存到相册或转发给朋友。

---

## 一、什么时候可以生成海报

只有 **「已结束」状态**（finished）的赛事才能生成海报。

赛事的完整生命周期：

```
报名中  →  小组赛  →  淘汰赛  →  已结束  ←—— 海报入口在这里出现
```

赛事进行中（报名 / 比赛阶段）暂时无法生成海报。等赛事走完淘汰赛、决出名次后会自动进入「已结束」。

---

## 二、入口在哪里

1. 打开小程序，进入「**赛事**」Tab
2. 点击列表里任意一场**状态为「已结束」**的赛事
3. 进入赛事详情页后，**右上角**会有一个分享图标（圆形按钮）
4. 点击后，会弹出选择面板：
   - **我的战绩卡** — 你在这场赛事的个人成绩
   - **赛事战报** — 整场赛事的全局战报（适合管理员或想分享整场的人）
5. 选一个，跳转到海报生成页

---

## 三、两种海报对比

### 1. 我的战绩卡（Personal）

属于你**自己**的个人战绩可视化，每位参赛者看到的内容不同。

| 区域 | 展示内容 |
|---|---|
| Hero（顶部） | 头像 + 姓名 + NTRP + ELO + 本次赛事名 + 日期 |
| Stats（本次成绩） | 4 项核心数据：名次 / 获得积分 / ELO 变化 / 战绩 W-L |
| Highlight（高光时刻） | 系统自动匹配的"值得分享的瞬间"（详见第五节） |
| Matches（本次记录） | 你在这场赛事打过的每一场比赛、对手、比分、胜负 |
| Footer | 球社品牌信息 |

### 2. 赛事战报（Tournament Report）

整场赛事的**全局战报**，所有人看到的是同一份内容。

| 区域 | 展示内容 |
|---|---|
| Hero（顶部） | 赛事名 + 日期 + 人数 + 单/双打 |
| Podium（前三名） | 冠 / 亚 / 季军头像 + 姓名 + 获得积分 |
| Stats（全场数据） | 3 项总览：总场次 / 决赛比分 / 满盘场次 |
| Roster（参赛阵容） | 全部参赛球员（最多展示 8 人，多余显示 +N MORE） |
| Footer | 球社品牌信息 |

## 四、6 种画风（可任意切换）

进入海报页后，**底部横向滑动**就能切换 6 种风格，画布会立即重绘。切换风格不影响内容，只换视觉皮肤。每种都是 750 × 1334 px 高清竖版，**可直接发朋友圈/聊天**。

## 五、高光时刻（Highlight）的判定逻辑

「我的战绩卡」会根据你在这场赛事的表现，**自动**为你挑一条最值得分享的"高光"。

**核心原则：永远正面**。无论你是第 1 名还是最后一名，系统都会找一个能让你愿意发朋友圈的角度。**绝不会**出现"被淘汰" / "首轮出局" / "爆冷被翻盘"等负面表达。

判定按以下 **8 级优先级**，从高到低取**第一个命中**的：

| 优先级 | 类型 | 触发条件 | 文案样式 |
|---|---|---|---|
| 1 | 以弱胜强 | 击败 NTRP 比自己高 ≥ 1.0 的对手 | 「击败 NTRP X.X 的 XXX」 |
| 2 | 决胜险胜 | 决胜局/决胜盘以 1 局之差获胜 | 「决胜局 X:X 力克 XXX」 |
| 3 | 小组全胜 | 小组赛阶段保持全胜（≥ 2 场） | 「小组赛 N 战全胜」 |
| 4 | 连胜势头 | 本次赛事内连胜 ≥ 3 场 | 「赛事中取得 N 连胜」 |
| 5 | 激战满盘 | 输球但打满最后一盘（虽败犹荣） | 「与 XXX 激战至最后一盘，虽败犹荣」 |
| 6 | 积分进账 | 获得名次奖励积分 | 「本次赛事获得 N 积分，实力稳步提升」 |
| 7 | 首次参赛 | 首次出战球社赛事 | 「首次征战，成功亮相」 |
| 8 | 稳健发挥 | 兜底，任何情况都能命中 | 「本次赛事第 N 名，持续在场」 |

**为什么这样设计？** —— 我们希望每位球友赛后都有动力把成绩晒出去，而不是因为没拿到名次而羞于分享。打球的快乐在过程，海报记录的是亮点。

## 六、保存到相册 / 转发给朋友

海报页底部有两个按钮：

### 「保存到相册」
- 第一次点击会**弹出微信原生授权窗**，需要允许小程序保存图片到你的相册
- 同意后，海报会以 **PNG 格式 750 × 1334 像素**保存到手机相册
- 如果之前误点了「拒绝」，再次点击保存按钮会引导你去**设置 → 隐私 → 相册**重新开启

### 「发送给朋友」
- 这个按钮会提示从**右上角微信菜单（… 三点菜单）**触发分享
- 微信原生分享面板会自动把当前画风的海报作为**分享卡片缩略图**
- 朋友点开会跳转到这场赛事的详情页

> 提示：如果你想直接发到朋友圈，建议先**保存到相册**，再从相册发朋友圈，画质更高（朋友圈支持完整尺寸图片）。

## 七、常见问题

**Q1：为什么我看不到分享按钮？**
A：赛事必须为「已结束」状态。报名中、小组赛、淘汰赛阶段都不会显示。等赛事走完决赛、产生名次后，按钮自动出现。

**Q2：我没参加这场赛事，能看到「我的战绩卡」吗？**
A：会进得去，但内容会显示空白（名次 —、积分 0、战绩 0-0）。这种情况建议你直接选「赛事战报」，看全局数据。

**Q3：我的高光时刻是「稳健发挥」，是不是说明我打得很差？**
A：不是。"稳健发挥" 是兜底文案，意味着以上 7 条特殊条件都没匹配上 —— 比如你打得平稳但没有特别突出的瞬间（没有以弱胜强、没有连胜、没满盘激战）。**这只是没有亮点条件命中，不代表水平**。

**Q4：保存的图片清晰度怎么样？**
A：海报输出为 **750 × 1334 px** 高清 PNG，相当于 iPhone 6/7/8 的 retina 标准。在所有手机上都能保证清晰显示，朋友圈不会被压糊。

**Q5：6 种风格里我最喜欢的是法网/温网/美网，但海报里某些字看不清？**
A：四大满贯风格用了不同字体，理论上 iOS 系统内置 Iowan Old Style 等衬线体显示效果最好。如果你在安卓上看到字体显示有差异，是系统字体回落的正常现象，不影响保存出来的图片。

**Q6：我能分享别人的战绩卡吗？**
A：「我的战绩卡」是基于**你当前登录账号**的数据生成的，无法生成别人的。但「赛事战报」是公共的，所有参赛者都能生成同一份。

**Q7：海报里的"小程序码"在哪？**
A：当前版本**暂未集成**小程序码。如果朋友看到海报想直接来报名，目前需要从微信里搜索"腾讯广州网球社"小程序进入。后续版本会在 footer 加上专属小程序码，扫码直达对应赛事页。

## 八、设计思路（给好奇的人）

### 为什么要做海报？
赛事结束后，单纯的"已结束"列表项很冷冰冰。海报是把数据**情绪化、可视化**，让球友愿意分享、让没参加的人想看，是球社活跃度的核心驱动。

### 为什么是 6 种风格？
- 1 套官方主色（emerald-heritage）保持品牌一致性
- 1 套运动潮流（sports）满足年轻化球友
- 4 套四大满贯主题让分享带情怀，每个赛季都有应景的视觉

### 为什么坚持"永远正面"？
单淘汰赛制下，每场都有一个输家。如果海报暴露"我输了" / "我被淘汰"，没人愿意发。**分享的前提是好看 + 体面**，所以系统从设计上就排除了任何让人不愿点保存的文案。

### 为什么是 750 × 1334 px？
- iPhone 标准 retina 宽度，rpx 基准 1:1 像素对齐
- 9:16 竖版完美适配微信朋友圈（建议 9:16）/ 聊天卡片
- PNG 无压缩，朋友圈分享不会糊掉
