## 1. 赛事类型

| 类型 | 标识 | 参赛单位 | 有无淘汰赛 |
|------|------|---------|-----------|
| 单打 | `singles` | 个人 | ✅ |
| 双打 | `doubles` | 两人组队 | ✅ |
| 团队赛 | `team` | A/B 两队 | ❌（一场定胜负） |

### 1.1 单打

- 报名 → 随机/种子抽签分组 → 小组循环赛 → 淘汰赛 → 决出冠军
- 每场小组赛 / 淘汰赛即时结算 ELO + 积分

### 1.2 双打

- 报名后管理员在前端完成「两两配对」
- 配对完成后抽签分组，每对作为一个「参赛单位」
- 胜负积分按**队员各拿满分**发放（不缩水）
- ELO 以队内**最高 ELO** 代表整队计算

### 1.3 团队赛

- 报名 → 管理员指定 A/B 队长 + 赛制 + 场地数 → 蛇形分队并分场 → 场内自由轮换
- 已录场次跨场地汇总 teamScore；平分时比较小分，仍平则由队长一球制胜
- 整场结束后一次性发固定加分，不修改 ELO
- 详见 [§7 团队赛](#7-团队赛)

## 2. 赛制（bestOf）

| 值 | 名称 | 适用赛事 | 比分规则 |
|:--:|------|---------|---------|
| 4 | 先赢 4 局 | 单打/双打（短盘） | 正常胜 4:n，延长胜 5:3，抢七 5:4 |
| 6 | 先赢 6 局 | 单打/双打（标准盘） | 正常胜 6:n，延长胜 7:5，抢七 7:6 |
| 7 | 单盘抢 7 | 单打/双打/团队赛 | 先到 7 分，净胜 ≥ 2；可延长至 8:6、9:7… |
| 11 | 单盘抢 11 | 单打/双打/团队赛 | 先到 11 分，净胜 ≥ 2；可延长至 12:10、13:11… |

## 3. 赛事生命周期

```
signup（报名中）
  │
  ├─ 管理员创建赛事
  ├─ 成员报名
  ├─ 管理员配组/选队长/设槽数
  │
  ▼ 抽签
group（小组赛）
  │
  ├─ 单/双打：小组循环，每场录比分 → 即时 ELO + 积分
  ├─ 团队赛：按场地确认上场人员 → 逐场录比分
  │
  ▼ 小组赛结束 → 进入淘汰赛
knockout（淘汰赛）
  │
  ├─ 单/双打：逐轮淘汰，录比分 → 即时 ELO + 积分
  │
  ▼ 淘汰赛完成
finished（已结束）
  │
  ├─ 发放名次奖（单/双打）
  ├─ 团队赛发固定加分，不修改 ELO
  └─ 写入 placementAwards
```

## 4. 积分体系

系统有**三条并行的数值线**，各自独立：

```
  tournamentEarnings（赛事收益）
       │
       ├─ 每场录分即时写入
       ├─ 名次奖一次性写入
       └─ 团队赛固定分写入
       │
       ▼ 取 earned 降序前 10 名 → totalPoints（排行榜）
```

### 4.1 单打 / 双打：每场即时加分

每录入一场小组赛或淘汰赛比分，双方参赛队员各获得：

| 分量 | 范围 | 计算 |
|------|:---:|------|
| 胜方每人 | **3 ~ 8 分** | `max(3, min(8, round(5 + 3×(1 - 期望胜率))))` |
| 负方每人 | **1 ~ 3 分** | `max(1, min(3, round(1 + 2×期望胜率)))` |

- ELO 差距越大，胜方加分越少（砍瓜切菜不加分），负方安慰分越多（虽败犹荣）
- 双打同队两人**各拿满分**（factor = 1，不再缩水）

### 4.2 名次奖（赛事结束时一次性发放）

| 名次 | 周赛 | 月赛 | 半年赛 |
|------|:---:|:---:|:---:|
| 🥇 冠军 | **50** | **100** | **200** |
| 🥈 亚军 | 30 | 60 | 120 |
| 🥉 四强 | 15 | 30 | 60 |
| 🏅 八强 | 8 | 15 | 30 |
| ✅ 参与 | 3 | 8 | 15 |

- 双打：同队两人**各拿满分**
- 团队赛：**不经过这套体系**（团队赛无 knockout 阶段）

### 4.3 团队赛：固定加分

| 角色 | 加分 |
|------|:---:|
| 胜方每人 | **+40** |
| 负方每人 | **+20** |

- 全队成员（含未上场替补）都拿
- 不进 placementAwards，不动 ELO

### 4.4 totalPoints 计算

```
totalPoints = tournamentEarnings
              .sort((a,b) => b.earned - a.earned)   // 按赛事收益降序
              .slice(0, 10)                          // 取前 10 场
              .reduce((sum, e) => sum + e.earned, 0) // 求和
```

每次积分变动后**即时重算**，排行榜始终展示最新数据。

## 5. ELO 等级分

### 5.1 基础算法

```
期望胜率 = 1 / (1 + 10^((对手ELO - 己方ELO) / 400))
ELO变化 = K × (实际结果 - 期望胜率)

胜方: +K × (1 - 期望胜率)
负方: -K × 期望胜率
```

初始值 = **1500**

### 5.2 K 值按赛制分流

| 赛制 | K 值 | 说明 |
|------|:---:|------|
| 先赢 4 盘 / 6 盘 | **16** | 多盘正赛，样本量最大 |
| 单盘抢 11 | **12** | 单盘中等偶然性 |
| 单盘抢 7 | **8** | 单盘偶然性最高 |

### 5.3 单打 / 双打的 ELO 基准

- **单打**：双方个人 ELO
- **双打**：取**队内最高 ELO** 代表整队（保守评估强度）
- 双打同队两人**同涨同跌**

### 5.4 团队赛与 ELO

- 团队赛只发放胜方 +40 / 负方 +20 的固定积分。
- 场地轮换、单双打组合和个人出场次数不统一，因此团队赛结果不修改个人 ELO。
- 上场阵容只用于个人战绩与报告，不参与 ELO 计算。

### 5.5 ELO History

- 每次 ELO 变动追加一条 `{ date, value, tournamentId }`
- 限长 **200 条**，防止数组无限膨胀
- 前端 `profile` 页以折线图展示

## 6. NTRP 评级

- **纯展示字段**，不参与任何积分/ELO 计算
- 用户可在「我的」页面直接点击 NTRP 卡片自选等级
- 可选值：1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 3.5 / 4.0 / 4.5 / 5.0 / 5.5 / 6.0 / 6.5 / 7.0
- 用途：报名时展示给其他人参考实力水平

## 7. 团队赛

### 7.1 组建流程

1. 管理员创建团队赛（不设 level，抽签时确定赛制和场地数）
2. 成员报名
3. 报名结束后，管理员打开「选队长 / 抽签」弹层：
   - 指定 A/B 队队长
   - 选定赛制（4 / 6 / 7 / 11）
   - 设定场地数（默认按每 6 人一片计算，可人工调整）
4. 系统按 totalPoints 蛇形分入两队（队长优先定位）
5. A/B 两队分别蛇形分到物理场地，保证每片场地同时有双方队员

### 7.2 录入流程

每片场地可自由轮换创建多场 A vs B 对局：

| 项目 | 规则 |
|------|------|
| 确认人员 | 先保存双方上场人员；每队最多 2 人且人数相同（1v1 或 2v2） |
| 录入比分 | 在已确认人员的场次上按 bestOf 校验（详见 §9） |
| 待录状态 | 同一场地一次只保留一个待录比分场次，人员不会因撤回比分而丢失 |
| 权限 | 场地队员可录本场比分；创建者/管理员可管理全部场地 |

### 7.3 胜负判定

```
teamScoreA = 所有场地正赛 encounter 中 winner === 'A' 的数量
teamScoreB = 所有场地正赛 encounter 中 winner === 'B' 的数量（不含一球制胜）

1) teamScoreA > teamScoreB → A 队胜
2) teamScoreB > teamScoreA → B 队胜
3) 相等 → 比较净胜局（gamesA : gamesB）
4) 净胜局也相等 → 两队队长进行「一球制胜」
```

### 7.4 结算

| 项目 | 规则 |
|------|------|
| 固定加分 | 胜方每人 +40，负方每人 +20（全员，含替补） |
| ELO | 团队赛不修改任何队员的 ELO |

## 9. 比分校验规则

### 9.1 多盘制（bestOf = 4 / 6）

| 场景 | 合法比分示例 | 规则 |
|------|------------|------|
| 正常胜 | 4:0, 4:1, 4:2, 6:0, 6:1…6:4 | winner = target, loser ≤ target - 2 |
| 延长胜 | 5:3, 7:5 | winner = target + 1, loser = target - 1 |
| 抢七胜 | 5:4, 7:6 | winner = target + 1, loser = target |

### 9.2 单盘抢分制（bestOf = 7 / 11）

| 场景 | 合法比分示例 | 规则 |
|------|------------|------|
| 未延长 | 7:0…7:5, 11:0…11:9 | winner = target, loser ≤ target - 2 |
| 延长 | 8:6, 9:7, 12:10, 13:11 | winner ≥ target + 1, 净胜 = 2 |

### 9.3 团队赛抢七决胜

| 合法 | 7:0…7:5, 8:6, 9:7, 10:8… |
|------|---------------------------|
| 非法 | 7:6（净胜不足 2）、6:5（未到 7） |

## 10. 撤回机制

### 10.1 触发条件

- 单打/双打沿用各自参赛方与管理员权限；团队赛只允许 creator/admin 撤回
- 前端按权限展示「撤回」按钮，后端再次校验

### 10.2 小组赛 / 淘汰赛撤回

| 操作 | 效果 |
|------|------|
| 冲销 ELO | 胜方/负方各自的 ELO 反向变动 |
| 冲销积分 | tournamentEarnings 中减去对应 pts，归零则删除条目 |
| 重算 totalPoints | 按最佳 10 场重算 |
| 清空 match | winner/score 清空，后续轮次对位清空 |
| 决赛 / finished | 同时清空 placementAwards，status 退回 knockout |

### 10.3 团队赛撤回

- creator/admin 可撤回指定场地内的一场比分，普通队员不能撤回。
- 撤回只清空 `setsA` / `setsB` / `score` / `winner`，保留 encounter 和双方上场人员。
- 撤回后重新汇总跨场地队际比分；已结束比赛不可重开。

### 用户（users）

|------|------|------|

| `matches[].courts` | array | 物理场地、场内队员及自由轮换 encounters |
| `teamSettlement` | object | 固定积分幂等结算与删除回滚凭证 |
