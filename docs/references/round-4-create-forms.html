共享组件 / Form primitives

3 页共用 · Claude Code 实施时直接抄
PRIMITIVE 01FORM-ROW
.form-row
每行 padding 12px 24px 14px，底部 1px var(--hairline) 实线。 所有 input/textarea 共用同一缩进。
.label: mono 9.5px uppercase muted + cn 12px fg。
.input: 系统 sans 15px fg，无边框，背景透明。
PRIMITIVE 02SEGMENTED
.segmented
替代微信原生 picker 灰色下拉。
2-4 列网格，1px hairline 边 + 内部 border-inline-start 分隔。
.is-active: bg var(--emerald-deep) + bg 文字 + 黄铜 em。
用于：level / type / bestOf。
PRIMITIVE 03STEPPER
.stepper
替代纯数字 input，避免误填。
3 列：− 按钮 / Iowan 衬线大数字 + mono 单位 / + 按钮。
用于：maxPeople / maxPlayers。
PRIMITIVE 04PICKER-TRIGGER
.form-row.is-picker
点击触发原生 datetime / locationPicker。
左侧 mono 标签 + 下方 Iowan 衬线值 + 右侧 → mono 箭头。
未选时 .value.empty 显示 mono 占位 "TAP TO PICK"。
用于：startTime / matchDate / scheduledTime。
PRIMITIVE 05CONTEXT-CARD
.context-card
match-create 专用。让用户清楚这场比赛属于哪个 tournament 的哪一轮。
发丝边卡：eyebrow + Iowan 标题 + 阶段 mono pill + meta-row（日期 / BO / 类型）。
从 tournament-detail 跳转过来时预填。
PRIMITIVE 06CTA-BAR
.cta-bar
所有创建页底部固定，position absolute, bottom 0。
左侧 mono 进度（"6 / 6 必填" + Iowan "已完成"）。
右侧 emerald-deep 主按钮 + ::after 黄铜金细线。
进度未满时左侧改为 var(--accent) "还差 1 项"，按钮 disable 灰色。
